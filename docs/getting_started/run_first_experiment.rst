Run your first experiment
=========================

DrEvalPy exposes the same experiment workflow through three interfaces:

- Use the :doc:`CLI quickstart </cli/quickstart>` to run an experiment from
  the terminal.
- Use the :doc:`Python quickstart </python/quickstart>` to load data, construct
  models, and run an experiment in Python.
- Use the `nf-core pipeline <https://nf-co.re/drugresponseeval>`__ to run experiments as a nextflow workflow.

Feel free to choose the interface that fits your workflow and environment best; all three use the same datasets,
models, evaluation logic, and result layout.
